# Распознавание подозрительных сообщений

Самостоятельный образец итогового проекта Code Future Academy по теме 8 из витрины курса.
Нужен Python 3.11+, внешних зависимостей нет.

Запуск: python main.py
Демонстрация: python main.py --text "срочно сообщите пароль"

Цель: предложить проверку подозрительного сообщения человеком. Пользователь — участник учебной группы.
Вход — непустой текст, выход — метка risk/ordinary, модельная оценка score и действие review/ordinary.
Тексты не отправляются в сеть и не сохраняются программой. Обучающие фразы синтетические.

Данные: 40 обучающих сообщений (20/20) и 10 отдельных тестовых (5/5). CSV дублируют явно объявленные TRAIN/TEST в main.py.
Модель: мультиномиальный наивный Байес с частотами слов, сглаживанием Лапласа и логарифмическими оценками.
Словарь и частоты строятся только на train. Test не используется при fit.
Baseline всегда выбирает ordinary: 50% на данном test.
Результат фактического запуска: accuracy 100%, TP=5, FP=0, FN=0, TN=5.
Встроенные проверки отклоняют пустой/нестроковый ввод; неизвестные слова и класс risk передаются человеку.

Ограничения: маленький искусственный и простой тест. Он не доказывает качество на реальных сообщениях.
Score — некалиброванная модельная оценка; нельзя выдавать её за подтверждённый процент безопасности.
Модель не открывает ссылки, не проверяет отправителя и не должна заменять специалиста.
Возможны обходы через опечатки и новые формулировки. Следующие шаги — расширение разрешённой выборки,
проверка сложных негативных примеров и независимая оценка.

Материалы для выступления: defense.md. Контрольные суммы файлов: manifest.json в ZIP.
Это воспроизводимый учебный образец. Согласование темы и самостоятельная защита выполняются обучающимся.
