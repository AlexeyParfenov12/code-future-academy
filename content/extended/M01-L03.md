## Как программа превращает данные в результат

У программы удобно различать три части: ввод, вычисление и вывод. Ввод получает исходные значения. Вычисление применяет к ним правило. Вывод показывает результат человеку или проверяющей системе. Для процента правильных ответов это количества ответов и вопросов → деление и умножение на 100 → напечатанный процент.

Python выполняет обычные команды сверху вниз. Поэтому имя нужно связать со значением раньше, чем оно понадобится в выражении. В строке `percentage = correct / total * 100` сначала вычисляется правая часть, затем результат связывается с именем `percentage`.

## Переменная — имя для значения

```python
correct = 15
total = 20
percentage = correct / total * 100
print(percentage)
```

Результат:

```text
75.0
```

После первой строки `correct` связано с целым числом 15, после второй `total` — с 20. Деление `/` даёт вещественное число 0.75. Умножение на 100 переводит долю в проценты. Значение 75.0 численно равно 75, а десятичная точка здесь связана с типом `float`.

Если изменить `correct`, уже рассчитанный `percentage` сам не пересчитается. Для нового результата нужно снова выполнить вычисляющую строку. Имя хранит связь с результатом конкретного вычисления, а не формулу электронной таблицы.

```python
correct = 15
total = 20
percentage = correct / total * 100
correct = 18
print(percentage)
percentage = correct / total * 100
print(percentage)
```

```text
75.0
90.0
```

## Почему число и строка ведут себя по-разному

`int` — целые числа, `float` — вещественные числа, `str` — текст. Кавычки создают строковое значение: `"15"` и `15` имеют разные типы. Это влияет на операции.

```python
print(15 + 5)
print("15" + "5")
print(type(15).__name__)
print(type("15").__name__)
```

```text
20
155
int
str
```

Для чисел `+` выполняет сложение, для строк — соединение. Строка `"155"` не является результатом арифметического сложения 15 и 5. Попытка разделить одну строку на другую завершится `TypeError`.

## Ввод и преобразование типов

`input()` читает одну строку и возвращает `str`, даже если пользователь набрал только цифры. Для арифметики текст нужно явно преобразовать. Целые количества читаются через `int`, величины с дробной частью — через `float`.

```python
correct = int(input())
total = int(input())
percentage = correct / total * 100
print(percentage)
```

Ввод:

```text
15
20
```

Вывод:

```text
75.0
```

Вложенный вызов читается изнутри наружу: сначала `input()` получает `"15"`, затем `int("15")` создаёт число 15. `int("15.5")` не подходит для десятичной дроби; нужен `float("15.5")`. Десятичный разделитель в такой записи — точка.

Подсказка внутри `input("Введите число: ")` тоже попадает в стандартный вывод. В обычной интерактивной программе это удобно. При точном сравнении stdout нужно следовать формату конкретного задания: добавленная от себя подсказка может изменить ответ. В готовых решениях сохранены те подсказки, которые предусмотрены исходными условиями.

## Формулы, скобки и единицы

Среднее четырёх оценок — сумма всех четырёх, делённая на 4. Скобки объединяют числитель.

```python
average = (4 + 5 + 3 + 5) / 4
print(average)
```

```text
4.25
```

Без скобок в `4 + 5 + 3 + 5 / 4` делится только последняя пятёрка. Поэтому ошибка в формуле может не вызвать исключения: программа запустится, но решит другую задачу.

В переводе минут в секунды коэффициент равен 60. Для 2.5 минуты получаем 150 секунд. Важно сохранять смысл величины: демонстрационный пример с метрами не превращает задание о минутах в перевод длины.

```python
minutes = 2.5
seconds = minutes * 60
print(f"{minutes} мин = {seconds} сек")
```

```text
2.5 мин = 150.0 сек
```

В формуле процента общее количество вопросов должно быть положительным. При `total = 0` деление не определено. Если условие гарантирует положительный ввод, решение работает в этой области; если такой гарантии нет, программе нужна отдельная проверка.

## Форматирование результата

`print` по умолчанию разделяет аргументы пробелами и завершает строку переводом строки. F-строка вставляет значения выражений в фигурных скобках. Формат `.2f` печатает два знака после точки, но не изменяет само исходное число.

```python
percentage = 15 / 20 * 100
print(f"Результат: {percentage}%")
print(f"Результат: {percentage:.2f}%")
```

```text
Результат: 75.0%
Результат: 75.00%
```

Оба значения численно равны, однако строки различаются. Для задания с точным stdout нужно выбирать именно указанный формат, включая регистр букв, пробелы, двоеточия и число строк.

## Три распространённые ошибки

**Строки вместо чисел.** Симптом — соединение цифр или `TypeError` при делении. Проверяем результат `input` и место преобразования через `int` или `float`.

**Неверный порядок вычислений.** Симптом — правдоподобное, но неправильное число. Подставляем маленький пример вручную и проверяем скобки, числитель и знаменатель.

**Несовпадение формата.** Число правильное, но вывод содержит лишнюю подсказку или отличается количеством знаков. Сравниваем итоговую строку с условием; не добавляем оформление от себя.
