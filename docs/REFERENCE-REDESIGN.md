# Code Future Academy: техническая библиотека

Работа продолжается в существующем React/TypeScript/Vite-проекте после коммита `0ad95ca`. Исправления PR №1 сохранены. Сайт публикуется в существующий GitHub Pages, новый проект или LMS не создаётся.

## Композиция

Первый экран: название справочника, краткое назначение, поиск и два прямых перехода — к ответам и к объяснениям. Вместо рекламного блока и сетки одинаковых плиток — индекс модулей с крупными типографическими номерами, строками занятий и реальными количествами материалов.

Левая колонка служит библиотечным индексом с раскрываемыми модулями. Читаемый центр шире боковых областей. Правая колонка содержит оглавление статьи и связи с другими материалами. Страница задания показывает короткое исходное условие, затем готовый ответ, копирование и iSMART; подробное объяснение раскрывается по желанию.

## Визуальная система

Графит `#111827`, бумажный фон `#F8FAFC`, белая поверхность, бирюзовый `#087F8C`, вторичный текст `#64748B`, границы `#E2E8F0`. Один основной акцент, янтарный используется только для неполноты или непроверенного статуса. Основной текст 16–18 px, подписи 13–14 px, код 14–16 px. Геометрия подчёркивает документ: тонкие линии, небольшие радиусы, свободные поля и моноширинная нумерация разделов. Тёмная тема использует ту же иерархию и контраст.

Код оформляется как редактор с отдельными строками и точным буфером копирования. Вывод программы, ошибочный код и готовый ответ различаются подписью, поверхностью и акцентной линией. Определения, пояснения и предупреждения выделяются разными средствами, а не набором одинаковых карточек.

Мобильная компоновка проверяется на 320, 375, 390, 768, 1024 и 1440 px. Код и документы прокручиваются внутри своей области; общий документ не расширяется. Навигация превращается в меню, а основные действия остаются рядом с ответом.

## Проверенные референсы

- [GitBook — Format content](https://gitbook.com/docs/create-content/formatting): просмотрена настоящая статья и её боковая навигация; взяты принципы читаемой колонки и связанного содержания.
- [MDN — Functions](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Functions): просмотрена статья с кодом, заголовками и переходами между темами.
- [Яндекс — ввод и вывод](https://contest.yandex.ru/tracks/python/basic-python-constructs/input-output-numbers-strings-formatting): просмотрены теория, примеры и оглавление статьи.
- [Vercel — vercel deploy](https://vercel.com/docs/cli/deploy): просмотрены компактные инструкции и техническая навигация.
- [Stripe — payments quickstart](https://docs.stripe.com/payments/quickstart): проверена текстовая структура с кодом. Визуальная загрузка завершилась таймаутом; визуальные детали Stripe не используются как проверенный факт.

Ни один интерфейс не копируется. Самостоятельные признаки Academy — библиотечный индекс курса, сквозная связь «документ → официальное задание → ответ → объяснение» и спокойная типографическая композиция без рекламных секций.

## Права и достоверность

Владелец подтвердил открытую публикацию студенческих материалов ранее и отдельно разрешил проверенные решения обычных практик из преподавательских материалов в этом задании. Это не распространяется на ключи контролей и аттестаций. Они исключаются на уровне генерируемых файлов, а не только кнопок.

Проверка локальным исполнением и проверка iSMART остаются разными статусами. Прямые адреса без студенческой сессии не обозначаются подтверждёнными. Исходники сохраняются отдельно; оригинальный PDF не заменяется пересказом. Для отсутствующего оригинального PDF явно обозначается конверсия исходного текста.
