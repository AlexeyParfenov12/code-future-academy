# Code Future Academy

Работающий учебный помощник по курсу iSMART «Разработчик интеллектуальных решений. Базовый уровень для студентов СПО (онлайн)». Содержание импортировано из `ismart_course_unpacked.zip`; учебная программа не заменена демонстрационными данными.

## Быстрый запуск

Нужны Node.js 22.12+ и npm. Для повторного импорта — Python 3.11+ (стандартная библиотека). Проверка в этой среде: Node 24, Python 3.14, Microsoft Edge.

```powershell
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite, обычно `http://127.0.0.1:5173/`. Маршруты используют HashRouter и работают на статическом хостинге без перенаправлений.

```powershell
npm run build
npm run preview
```

Сборка автоматически проверяет размещение текста всех слайдов. На Windows используется установленный Edge; на Linux/macOS предварительно выполните `npx playwright install chromium`. Повторная сборка с неизменёнными слайдами использует проверенные контрольные суммы. `dist/` можно разместить на обычном статическом хостинге или открыть через `python -m http.server 8080 --directory dist`.

## Что импортировано

- 5 модулей, включая итоговую аттестацию; 82 раздела: 74 занятия и 8 контролей.
- 74 лекции и 74 презентации, 1 239 слайдов.
- 743 сопоставленных элемента платформы и 653 официальных практических элемента.
- 723 практических элемента сайта: официальные элементы, задания из студенческих практик и авторские дополнения. Авторские упражнения обозначены отдельно; число элементов сайта не тождественно числу страниц iSMART.
- 49 уникальных CSV/IPYNB, 67 привязок разрешённых студенческих файлов (также PDF), скачиваемые студенческие PPTX.
- 16 тем с дополнительной авторской практикой. Подтверждены 73 раздела с материалами преподавателя и 284 представления закрытых вариантов; их содержимое в сайт не включено.

Полный машиночитаемый отчёт: `public/content/import-report.json`, в интерфейсе — «Состав и источники». В HTML сохранённых страниц обнаружено 156 адресов документов; в метаданных занятий — 155. Дополнительная ссылка ведёт на `README.md` занятия 1.16: сам файл отсутствует в комплекте. Он отмечен отсутствующим, а не подменён новым файлом.

## Обновление материалов

```powershell
python scripts/import_course.py --source "C:\путь\ismart_course_unpacked.zip" --private-output "C:\путь\private-ismart"
npm run slides:fit
npm run build
```

Вместо ZIP можно передать каталог с распакованным комплектом. `--private-output` обязательно находится **вне папки проекта**. Импорт не исполняет Python, ноутбуки, макросы или JavaScript архива. ZIP проверяется на выход за каталог распаковки; старые абсолютные пути из метаданных не используются для чтения файлов за пределами архива. Обновление заменяет только генерируемый `public/content/`. Остановите импорт до проведения браузерных тестов: каталог обновляется целиком.

Первым источником порядка служит `Состав комплекта.json`, он сверяется с реестром, служебными документами, снимками и фактическими файлами. Нумерация задаёт стабильные ID, например `M01-L03`, `M03-L16`, `M03-L17`, `M01-C1-4`. ID официальной задачи основан на element ID iSMART. Повторяющиеся названия занятий не объединяются. Для авторских упражнений ID состоит из занятия и исходного номера задания; при изменении нумерации авторских упражнений нужно вручную сохранить соответствие ID в импортёре.

Оригиналы остаются в исходном ZIP/каталоге. Производные лекции очищены от служебных ссылок и адаптированы для самостоятельного чтения; изменения перечислены на странице занятия. Дополнительный учебник хранится отдельно в `src/learning.ts` и явно обозначен авторским материалом Academy.

## Презентации

Импортёр читает DrawingML и переносит геометрию, заливки, шрифты, текст и таблицы подготовленных презентаций в SVG. В данном комплекте все элементы поддержаны: прямоугольные фигуры и таблицы; неподдерживаемые фигуры у будущих архивов попадут в предупреждения. Заметки преподавателя не читаются в веб-представление.

`scripts/fit-slides.mjs` проверяет реальные размеры текста в браузере. В этой версии 18 блоков получили минимальное уменьшение шрифта, чтобы исключить обрезание. Геометрия слайдов сохранена. Отчёт преобразования и SHA-256 — `public/content/slide-render-report.json`. Это веб-представление, а не заявление о попиксельном совпадении с PowerPoint. Перед публичным выпуском полезна сверка с оригинальным приложением.

Студенческая PPTX — отдельная производная копия без заметок, комментариев и персональных метаданных. Оригинальная PPTX не изменяется и не попадает в публичную папку. Ноутбуки сохраняются без выводов ячеек, счётчиков выполнения и метаданных. CSV/PDF копируются с проверкой SHA-256.

## Решения и права доступа

По умолчанию готовые ответы из преподавательских материалов **не опубликованы**. Стартовый код, демонстрационный пример и ожидаемый вывод не выдаются за окончательный ответ. Полный код в студенческой практике доступен как учебный пример с точным копированием отступов.

Для обычных практик реализована публикация индивидуально проверенных решений через локальный манифест `--publication-review`. Формат описан в `docs/publication-review.example.json`. В записи нужны настоящий task ID, проверенный код, его SHA-256, разрешение правообладателя, имя проверившего и дата. Пример по умолчанию не разрешён к публикации. Контроли, промежуточные аттестации и итоговая защита этим механизмом не открываются. Статусы `unreviewed`, `locally_verified`, `approved`, `published`, `teacher_only` разделены. Уровни проверки `source`, `local`, `project_tests`, `ismart` не смешиваются; для подтверждения проверки нужно записать фактическое доказательство.

Пример запуска после заполнения и реального утверждения манифеста:

```powershell
python scripts/import_course.py --source "C:\путь\ismart_course_unpacked.zip" --private-output "C:\путь\private-ismart" --publication-review "C:\путь\approved-solutions.json"
```

Закрытые источники, оригинальные ответы, полные metadata со служебными адресами и сведения о вариантах находятся в `--private-output`, а не в `public`, `src` или JS-бандле. Преподавательская веб-панель не создавалась: в этой версии управление осуществляется локальным импортом. Будущая панель должна хранить закрытый контент на сервере и авторизовать каждый запрос; скрытие кнопок в React недостаточно.

Версия Sites предназначена для **частного доступа владельца**. Перед изменением аудитории на открытую нужно подтвердить права iSMART. Не размещайте исходный архив и приватный индекс рядом со статической сборкой.

## iSMART

Из исходных URL извлечены unit ID и element ID. Кандидаты прямых адресов сохраняют только наблюдавшийся путь `/course/practice/...`, без преподавательского интерфейса и параметров возврата. Все они имеют `unverified`: авторизованная студенческая сессия не предоставлялась.

Пока ссылка не подтверждена, кнопка показывает маршрут поиска по курсу, занятию и элементу, а не отправляет пользователя по потенциально неподходящему адресу. Открыть можно официальный вход iSMART в новой вкладке. Оценивание, отправка и проверки платформы не имитируются. Автоматического входа, обращения к закрытым API и вставки кода в iSMART нет.

## Возможности приложения

Каталог всех модулей и занятий, поиск по полному тексту лекций и практик (Fuse.js), фильтры заданий, безопасный Markdown, Shiki с Python, копирование, браузерный просмотр слайдов с навигацией/полным экраном/объяснением, CSV preview, PDF и IPYNB, связанные темы и следующий элемент. Учебник, справочник ошибок, подготовленные трассировки девяти алгоритмов, интерактивный график линейной модели и чек-лист защиты дополняют материалы курса.

Тёмная тема, избранное, недавно открытые занятия, прогресс, черновики ответов и личные источники хранятся в localStorage. Они не передаются на сервер и не являются официальными оценками. Кнопка копирования сообщает об успехе только после успешного обращения к Clipboard API; при отказе предлагает выделение и ручное копирование. Трассировки обозначены подготовленными, настоящего исполнения Python в приложении нет.

Проверенные адреса официальной документации Python, Pandas и Scikit-learn связаны с темами. Неподтверждённые видеоссылки не добавлены. Личный источник можно добавить в браузере; он помечается непроверенным и не публикуется для остальных посетителей.

## Проверки

```powershell
npm run test
python -m unittest discover -s tests -p "test_*.py" -v
# В другом терминале оставьте npm run dev
npm run test:e2e
npm run build
```

Vitest проверяет учебные трассировки и связанные темы. Python проверяет ZIP traversal, активный HTML, преобразование служебных ссылок, уникальность ID, все 1 239 файлов слайдов, все 74 очищенные PPTX, контрольные суммы файлов и отсутствие преподавательских URL/старых персональных путей в публичном контенте. Playwright открывает все 82 раздела и проверяет слайды, CSV, clipboard, поиск, фильтры, сохранение прогресса/темы/закладок и мобильную ширину 390 px.
