# Code Future Academy

[Открыть сайт](https://alexeyparfenov12.github.io/code-future-academy/) · [Репозиторий](https://github.com/AlexeyParfenov12/code-future-academy)

Справочная библиотека курса iSMART «Разработчик интеллектуальных решений» для студентов СПО. Сайт помогает найти исходные материалы, скопировать готовый ответ и разобраться в решении. Готовые решения сгруппированы по модулям и занятиям; выбор хранится в URL и сохраняется после обновления или возврата из задания. Официальная сдача проходит на iSMART.

## Содержание

- 5 модулей, 74 публичных раздела: занятия и документы аттестаций.
- 381 уникальный официальный элемент обычной практики; у каждого опубликован ответ и объяснение. Проектные работы обозначены образцами.
- 225 программ с 304 воспроизводимыми тестовыми запусками. Текстовые ответы и расчёты сверены с условиями; они не выдаются за запуски Python.
- 74 лекции в PDF: 13 исходных PDF сохранены побайтно, 61 конверсия сделана из исходного HTML с таблицами и схемами.
- 36 оригинальных презентаций iSMART: 497 слайдов, студенческая PPTX и PDF-копия через штатный экспорт Microsoft PowerPoint. Подготовленные владельцем презентации исключены. Для 38 разделов оригинал отсутствует в архиве — вместо замены показано сообщение и переход к исходной лекции.
- Дополнительный учебник Python, объяснения математических и ML-тем, подробные лекции, справочник ошибок, тематические источники и избранное.
- Скачиваемый самостоятельный пример комплекта проекта 4.13: код, синтетические данные, паспорт, ожидаемый отчёт и контрольные суммы.

Полный исходный реестр из 82 разделов хранится вне публичного проекта. Восемь текущих контролей доступны отдельными ссылками в разделе «Контроли и аттестации» вместе с четырьмя промежуточными аттестациями и итоговой защитой. Контроли не создают пустых страниц лекций и не входят в счётчик лекций. В навигации контролей опубликованы только названия и восстановленные студенческие ссылки, без вопросов и ключей. Ключи аттестаций, закрытые варианты и преподавательские документы исключены из публичных файлов. Право на публикацию студенческих материалов и проверенных ответов обычной практики подтверждено владельцем отдельно.

На сайте нет учёта прохождения, сохранения черновиков, дополнительных авторских заданий и отдельного тренажёра. Старые маршруты перенаправляются в библиотеку. При обновлении сохраняются только избранное, недавно открытое, тема и личные ссылки.

## Локальный запуск

Нужны Node.js 22.12+ и Python 3.11+. Проверено: Node 24, Python 3.12.14, Microsoft Edge.

```powershell
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5173/. В разработке изменения появляются автоматически. Для сборки:

```powershell
npm run build
npm run preview
```

HashRouter позволяет открывать страницы на GitHub Pages. Для пути проекта при сборке задайте GITHUB_PAGES_BASE=/code-future-academy/. Готовые PDF и PPTX включены в репозиторий. Обычная сборка не требует Microsoft Office. Для повторного преобразования оригинальных PPTX нужен Microsoft PowerPoint на Windows; скрипт открывает их только для чтения, без окон презентаций и с отключёнными макросами. PDF-конверсии кешируются по SHA-256 исходной PPTX вне публичного проекта. Для повторного преобразования HTML-лекций нужен Edge на Windows или Chromium через npx playwright install chromium на Linux/macOS.

## Проверка

```powershell
python -m pip install -r scripts/requirements.txt
npm test
python -m unittest discover -s tests -p 'test_*.py' -v
npm run test:e2e
```

Для повторного исполнения опубликованных решений создайте окружение Python 3.12 и установите отдельные зафиксированные зависимости:

```powershell
python -m pip install -r scripts/requirements-solutions.txt
python scripts/verify-solutions.py --report solution-replay.json
```

Проверка запускает только явно рассмотренный код из content/solutions в отдельных временных каталогах с привязанными студенческими файлами. Архивные программы не исполняются автоматически. Для проверяемой функции без вывода используется отдельный тестовый harness; он не попадает в копируемое решение.

Браузерные проверки охватывают 74 маршрута, поиск по номеру и темам, выбор модуля и занятия с обновлением и возвратом, точное копирование с нормализацией системных CRLF, внутренние ссылки, просмотр документов, слайды, избранное, смену темы, миграцию данных и ширины 320/375/390/768/1024/1440.

## Повторный импорт

```powershell
python scripts/import_course.py --source "C:\путь\ismart_course_unpacked.zip" --private-output "C:\путь\private-ismart" --rights-confirmed
```

Зависимости импортёра находятся в scripts/requirements.txt. Вместо ZIP можно передать подготовленный каталог. Приватная папка должна находиться за пределами проекта. Импорт проверяет пути ZIP, сохраняет полный исходный реестр отдельно, применяет публичную проекцию и рассмотренные манифесты решений, затем строит PDF и самостоятельный пример проекта. Он не исполняет исходные Python/ноутбуки/макросы. Импорт обновляет public/content целиком, поэтому его следует завершить до браузерных тестов.

Стабильные ID основаны на element ID iSMART. Занятия 3.16 и 3.17 сохраняются раздельно несмотря на одинаковое название. Синтаксис и отступы восстанавливаются только при совпадении с полным доверенным блоком, включая содержимое строковых литералов. Изменения исходных материалов и собственные реализации не смешиваются.

## Происхождение и ограничения

Источник: ismart_course_unpacked.zip, SHA-256 54def6f73c76657f86cbc0ad8f2a95dc8071240844a93c85d6584da0dcdcef51.

Оригинальные PPTX остаются в закрытом комплекте без изменений. Скачиваемые студенческие копии не содержат заметок, комментариев и персональных метаданных. Ноутбуки очищены от выводов, счётчиков выполнения и метаданных. Исходные CSV и разрешённые PDF проверяются по SHA-256.

Прямые ссылки iSMART восстановлены из архива, но не проверены в авторизованном студенческом кабинете. Это явно указано рядом с кнопкой; предусмотрен переход на главную платформы. Локальная проверка ответа не объявляется успешной сдачей на iSMART.

README.md занятия 1.16 отсутствует в архиве. В виджете 2.17/3.1 повреждены подписи части диапазонов. Эти ограничения отмечены в отчёте; файлы и подписи не выданы за восстановленные оригиналы. Некоторые исходные программы 4.12–4.13 потеряли отступы: опубликованные самостоятельные реализации обозначены отдельно, анализ исходной логики назван ручной трассировкой.

Машиночитаемые отчёты: public/content/import-report.json, solution-coverage.json, document-report.json, slide-render-report.json, presentation-report.json. В интерфейсе — «Состав и источники». Дизайн и источники решения описаны в docs/REFERENCE-REDESIGN.md.

GitHub Actions проверяет материалы и собирает сайт при обновлении main; публикация выполняется в существующий GitHub Pages.
